## Технические заметки (волна 2)

- **Фото из ВК**: userapi.com блокируется сетью; обход — прокси `https://images.weserv.nl/?url=<url-encoded без https://>`. Страницы vk.com отдаются curl'ом с браузерным UA; альбом: `vk.com/photos-<group_id>`, в HTML лежат `sun*-*.userapi.com/...as=32x..,..,MAXxMAX` — брать максимальный размер из списка `as=` через `&cs=WxH`.
- **Фото из Яндекс.Карт**: карточка `yandex.ru/maps/org/<slug>/<id>/` curl'ом → `avatars.mds.yandex.net/get-altay/<ns>/<hash>/orig`. Первые уникальные id = og:image/preload (фото организации), `alt="... <город>, photo"` = её галерея; дальше идут фото отзывов и соседних организаций — отбирать глазами.
- **Шрифты**: `pipeline/vendor_fonts.py` — принимает словарь семейств/весов, качает woff2 и пишет fonts.css.
