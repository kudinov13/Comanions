# DESIGN.md — СМЕЛО + ЧИСТО (сайты уровня $10k)

«Дёшево» — это когда НЕТ смелости (безопасный минимализм, тонкие рамки, мелкий текст) ИЛИ когда кривое исполнение (наложения, слабый контраст). Смелость и чистота обязательны ОДНОВРЕМЕННО.

## 1. До кода

Сначала пройти `CONTENT.md` и Content Readiness Gate. Затем отдельный art director создаёт `concept-board.md` по `ART_DIRECTION.md`: Design Read, variance/motion/density, продуктовый сценарий, материал, композиционная ДНК, карта тишины, типографика, image treatment, функциональная интеграция и anti-goals. Motion фиксируется до кода по `MOTION.md`.

Десять строк могут быть кратким резюме, но не заменяют dossier и concept board.

## 2. СМЕЛОСТЬ — без этого брак
- Hero обязан давать «вау»: oversized типографика (заголовок ≥ 8vw) ИЛИ full-bleed фото с наложенной композицией ИЛИ крупный цветовой блок ИЛИ signature-интерактив.
- Минимум 2 смелых жеста на страницу: гигантские цифры, marquee, повёрнутый штамп/стикер, контрастная тёмная секция после светлой, фото на всю ширину, огромный рейтинг.
- Палитра с характером: тёмный фон + яркий акцент норм; насыщенные цветные секции норм; пастель только если это ИДЕЯ бренда.
- Display-шрифт доминирует: крупный, узнаваемый, задаёт настроение. Не Inter/Roboto.
- Запрещён «тихий» сайт: тонкие линии + мелкий текст + воздух без идеи = шаблонное агентство = брак.

## 3. ЧИСТОТА — крафт, не опция
- Контраст текста ≥4.5:1; текст на фото — только поверх контролируемого затемнения/градиента.
- Ничего не перекрывается на 1440/1024/375px; декор в углах или скрыт на узких экранах.
- Кнопки одной высоты на одной базовой линии; один главный CTA.
- Хайлайт слова — ровной заливкой на самом элементе (`box-decoration-break:clone`), не косым псевдоэлементом.
- Motion — только из storyboard в `MOTION.md`; общий fade/translate reveal каждой секции запрещён; `prefers-reduced-motion` обязателен.
- Фейковые цены/отзывы/календари/цифры — запрещены. Только данные из анализа.

## 4. Язык дорогого дизайна
- Один signature-приём из сути бизнеса, максимум 2 повторения на страницу.
- Ритм: чередуй плотные/воздушные секции, светлые/тёмные, типографика/фото.
- Фото единообразно обработаны (grayscale/contrast/sepia фильтром).
- Факты — плакатом: рейтинг, цены, площади крупно, это акценты.
- Акцент ≤ ~15% площади — НО он яркий и уверенный, а не размазанный.

## 5. Проверка до сдачи
1440/1024/375: нет горизонтального скролла, нет перекрытий, нет одиноких слов в заголовках, кнопки в линию, контрасты ок. Squint-тест: видна иерархия. Без JS сайт цел. Самооценка ≥8 по: вау-фактор hero / уникальность / иерархия / аккуратность / мобильность. Первый пункт провален — переделать hero.

## 6. Правило серии
В одной волне запрещены два сайта с одинаковыми: светлотой фона, акцентным цветом, композицией hero, типографической парой, signature-приёмом — **И СКЕЛЕТОМ СТРАНИЦЫ** (см. §6.1).

## 6.1 Композиционная ДНК — критический пункт, чинит «сайты под копирку»

**БАН-СКЕЛЕТ** (выловлен в волне 2 — оба сайта им вышли): `липкий topbar → hero 2 колонки (текст слева + фото справа) → marquee → сетка 3 цифр → галерея → CTA → футер`. Это шаблон SaaS-лендинга. Если скелет совпал — брак, независимо от палитры.

Композиция выводится из ФОРМАТА бизнеса, а не из «разделов лендинга». Сначала выбери формат-документ, потом строй страницу по его грамматике:

- **афиша/постер** (бары, фуд, события): одна вертикальная композиция, гигантское имя пересекает фото, адрес как штамп, никаких «2 колонки hero»
- **открытка/письмо** (глэмпинги, бани, усадьбы): full-bleed фото + бумажная карточка поверх края, марка, подпись от руки, дневниковые записи вместо «услуг»
- **досье/документ** (уже занято «Делом Левина»): поля дела, улики, штампы
- **редакционный разворот** (студии, салоны): journal grid, номера полос, рекламная пауза
- **улица/районная объявление** (занято «Лезвиями»): асфальт, столб-листовки, marquee района
- **меню-борд/чек-лист** (кафе, еда): доска с позициями, тикет на выходе
- **каталог-витрина** (товарные ниши): ценник-плакат, полки
- **карта/маршрут** (турбазы, глэмпинги): точка на маршруте, «как доехать» как линия пути

Проверка скелета: опиши страницу списком зон (`зона1 → зона2 → …`) и сравни с другими сайтами волны — если последовательность зон читается одинаково, меняй формат.

**Запрещённые дефолтные приёмы hero** (признак ленивого шаблона): «h1+абзац+2 кнопки слева, фото справа», «фото-затемнение во весь экран + центрированный текст», «3 одинаковые карточки преимуществ». Хоть один из этих паттернов = переделать hero: допустимы full-bleed с композицией ПОВЕРХ, постер по центру, коллаж из фото разных размеров, вертикальная гигантская надпись, разрез/наслоение фото и типографики, интерактив-смысл.

## 7. Механические числа (для слабых моделей — не рассуждать, а соблюдать)
- Заголовок hero: `clamp(44px, 8–11vw, 120–150px)`; перенос строк задавать `<span class="row">` — никаких случайных переносов и одиноких слов.
- Кнопки: одна высота на весь сайт (`height:52–56px`), один класс; в строке CTA не больше 2 кнопок.
- Отступы секций: `clamp(56px, 8–12vw, 108–150px)`; внутренние — вдвое меньше.
- Декоративные рамки/линии: только статичные `::before/::after` с фиксированными px-отступами; НЕ собирать стрелки/засечки из 4+ псевдоэлементов — это едет на промежуточных ширинах. Простая линия + чип-подпись лучше сложной.
- Хайлайт слова: заливка на самом элементе + `box-decoration-break:clone`.
- Marquee: контейнер `overflow:hidden`, трек `width:max-content`, две одинаковые группы для бесшовного `-50%`.
- Текст поверх фото: только поверх `linear-gradient` затемнения.
- Проверка шрифтов: перед сдачей убедиться, что у каждого локального woff2 есть кириллический сабсет для используемых family/weight — иначе сменить шрифт, а не молча фолбэчить.

## 8. Финальные гейты оркестратора

Отчёт билдера ≠ истина. До показа оркестратор сам проверяет:

0. **Content**: Content Readiness пройден; каждая цифра/цена/позиция трассируется к Fact ledger, каждый `img/` — к Asset ledger; подписи совпадают с тем, что видно на фото.
1. **Product**: сайт помогает выбрать и совершить действие ниши; категории-заглушки и moodboard вместо меню/каталога/брони — FAIL.
2. **Concept**: зоны совпадают с concept board, метафора управляет всей страницей, а не hero; сравнить с бан-скелетом и другими сайтами волны.
3. **Anti-slop**: пройти ART_DIRECTION.md §12 — material, prop audit, quiet map, типографическая и функциональная полнота.
4. **Motion**: каждый эффект есть в storyboard; grep `gsap.from|data-reveal|data-rise`; универсальный fade-up и незаявленные loops — удалить.
5. **Runtime**: внешние `src/href/url()` — только разрешённые контакты/карты/booking destinations; ноль runtime-загрузок ассетов.
6. **Encoding/fonts**: нет `Рџ`, `вЂ`, мусора; локальные woff2 содержат кириллицу для каждого используемого family/weight.
7. **Responsive**: прочитать все `@media`; у сеток есть узкий вариант, у абсолютного декора safe-offset/hide; hero-переносы детерминированы.
8. **Visual QA**: отдельный QA-agent выполнил `VISUAL_QA.md`; есть screenshots и `verdict.md`; 0 Blocking и 0 Major.
9. **Evidence**: оркестратор выборочно открывает screenshots и фото, не принимает PASS агента вслепую.

Любой FAIL возвращает работу на правильный этап: данные → Content Dossier, системная визуальная проблема → Concept Board, локальные дефекты → Fixer. Не лечить отсутствие продукта косметикой.
