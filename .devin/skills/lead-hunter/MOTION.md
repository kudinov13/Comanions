# MOTION.md — движение как часть метафоры

Motion — не полировка и не обязательная характеристика премиального сайта. Он допускается только когда движение передаёт смысл концепта или улучшает действие пользователя.

## 1. Запрещённый дефолт

Запрещено анимировать каждую секцию одинаковым `opacity + translateY` через GSAP/ScrollTrigger. Запрещены универсальные `.reveal`, `[data-rise]` и stagger всех карточек без смысловой причины.

Также по умолчанию запрещены:
- scroll-jacking;
- длинные pinned-секции;
- параллакс ради параллакса;
- одновременная анимация более двух крупных акторов;
- бесконечные декоративные loops около текста;
- motion, который скрывает контент до выполнения JS.

## 2. Decision tree

1. Есть ли у концепта физическое/смысловое действие: рисование, штамп, путь, проявление, пар, печать, перелистывание?
   - нет → только hover/focus/loading states;
   - да → перейти дальше.
2. Помогает ли движение понять продукт или завершить действие?
   - нет → удалить;
   - да → записать в storyboard.
3. Можно ли сделать Tier 0/1?
   - да → не использовать Canvas/WebGL;
   - нет → Tier 2 только для signature-эффекта.
4. Есть ли статичный и reduced-motion fallback?
   - нет → эффект запрещён.

## 3. Motion Storyboard Gate

До кода `concept-board.md` содержит:

```markdown
| # | Зона | Что движется | Почему движение = смысл | Tier/техника | Триггер | Mobile/reduced fallback | Вес |
|---|---|---|---|---|---|---|---|
| M01 | hero | кисть открывает название | афиша проявляется как ручная печать | T0 SVG mask | load once | сразу открыто | inline |
```

Правила:
- пустое «почему» → эффект удалить;
- максимум 4 строки: 1 hero-жест, 2 второстепенных, 1 ambient;
- «reveal секции» без метафоры — брак;
- Tier 2/3 требует прямого обоснования signature-приёмом;
- storyboard фиксирует ассеты до реализации.

## 4. Техники

### Tier 0 — CSS/SVG
- SVG path draw через `pathLength`, `stroke-dasharray`, `stroke-dashoffset`;
- brush reveal через SVG mask + `feTurbulence`/`feDisplacementMap`;
- CSS mask reveal;
- 3–4 SVG-варианта линии с `steps(1)` для hand-drawn boil;
- stamp/press через короткий scale/rotate с осмысленным финальным состоянием.

### Tier 1 — локально сгенерированные ассеты
- 8–16 SVG/PNG/WebP-кадров;
- sprite sheet + `steps(N)`;
- rough alpha mask;
- генератор с seeded jitter, чтобы результат воспроизводился.

Ассеты лежат в `site/motion/`, а генератор — рядом с проектом или в общем pipeline. Исходные кадры не загружаются с CDN.

### Tier 2 — Canvas 2D
Допустим для естественных частиц: снег, пар, искры, дым, пыль. Требования:
- один canvas-effect на страницу;
- ≤80 частиц desktop, ≤40 mobile;
- `devicePixelRatio` cap 2;
- pause через IntersectionObserver и `document.hidden`;
- контент остаётся доступен без canvas.

### Tier 3 — WebGL
По умолчанию запрещён. Допустим только если шейдер — центральный signature-приём, а не фон. Нужен отдельный статичный fallback и явное решение оркестратора.

## 5. Покадровая «рисованная кисть»

Агент может создавать Fable-подобный эффект локально:

1. нарисовать исходный SVG path;
2. сгенерировать 4–16 вариантов с небольшим seeded jitter;
3. переключать кадры на 8–12 fps через sprite/steps;
4. сохранить конечный кадр как статичный fallback;
5. отключить loop при reduced motion.

Fable — отдельный motion-design инструмент, а не модель. Он не требуется для простых path/brush/sprite эффектов.

## 6. Бюджеты

- Motion JS без библиотек: ориентир ≤10 KB.
- Один sprite/effect: ≤150 KB WebP.
- Все motion-assets страницы: ≤400 KB.
- Hand-drawn animation: 8–12 fps.
- Canvas: requestAnimationFrame, graceful degradation при frame time >33 ms.
- Mobile: частицы вдвое меньше, hover-motion выключен.
- Вне viewport: loops и canvas paused.
- `prefers-reduced-motion`: loops off, draw сразу в конечное состояние.
- Без JS: вся информация и финальные состояния видимы.

GSAP подключать только если есть минимум три осмысленных tween или сложная синхронизация. Иначе CSS/SVG/нативный JS предпочтительнее.

## 7. Motion должен реагировать на продукт

Примеры допустимой связи:
- еда: кистевой мазок открывает блюдо, искры гриля — один ambient;
- глэмпинг: линия маршрута рисуется, пар поднимается над чаном;
- ремонт: чертёж проявляется линиями;
- фотограф: кадр проявляется как фотобумага;
- магазин: штамп подтверждает выбранный товар;
- автомастерская: индикатор диагностики показывает реальный этап.

Нельзя переносить один эффект между нишами только потому, что он красиво работал в прошлом проекте.

## 8. Interaction quality

Motion не заменяет состояния интерфейса. Обязательны:
- hover/focus/active без зависимости от мыши;
- touch target ≥44×44;
- feedback после действия;
- no-motion вариант;
- отсутствие CLS;
- анимация transform/opacity/mask вместо width/height/top/left, если возможно.

## 9. QA

Visual QA проверяет:
- эффект соответствует storyboard;
- нет незаявленных reveal-анимаций;
- первый экран не скрыт до загрузки JS;
- reduced-motion работает;
- mobile не перегружен;
- animation не конкурирует с CTA;
- canvas/loop прекращается вне viewport;
- вес соответствует бюджету.

Любой motion вне storyboard — major issue; блокирующий доступ к контенту — blocking issue.
