# Subagents — конвейер лидов РФ для веб-студии

Субагенты ищут молодые компании без сайтов (2ГИС/Яндекс.Карты/VK/Zoon/Yell), верифицируют отсутствие сайта по чеклисту, строят премиальный сайт-концепт с реальными данными и готовят письмо владельцу.

## Структура

```
Subagents/
├── .devin/skills/
│   ├── lead-hunter/
│   │   ├── SKILL.md   — мастер-инструкция конвейера (6 этапов)
│   │   └── DESIGN.md  — анти-шаблонный дизайн-гейт (СМЕЛО+ЧИСТО, код-гейт оркестратора)
│   ├── subagent-orchestrator/ — дисциплина оркестрации волн
│   └── sales-скилы: cold-email, objection-handling, negotiation, discovery-call,
│       proposal-pricing, lead-research, linkedin-outreach, outbound-sequence и др.
└── pipeline/YYYY-MM-DD/
    ├── STATE.md       — точка остановки между сессиями (читать первым)
    ├── leads.md       — сводная таблица статусов
    ├── hunt-*.md      — выдача охотников (кандидаты + отбракованные)
    └── <company>/     — analysis.md + site/index.html + offer.md
```

## Запуск (новая волна)

```
Прочитай .devin/skills/lead-hunter/SKILL.md (+ DESIGN.md для билдеров).
Запусти охотников по кластерам ниш → отбери топ по скорингу (вручную перепроверь чеклист «сайта нет») 
→ билдеры 1 компания = 1 субагент = 1 папка → код-гейт + Design Gate → отдать offer.md пользователю.
```

## Продолжение после сессии

Читать `pipeline/<последняя-дата>/STATE.md` — там отобранные лиды, тех. заметки (обходы userapi.com через images.weserv.nl, фото Яндекс.Карт через get-altay) и следующий шаг.
